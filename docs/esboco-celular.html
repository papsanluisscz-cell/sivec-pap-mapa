Técnicamente se llama “aplicación web progresiva”: se ve y se usa como una app, pero no se instala desde una tienda.
¿Cuándo sí haría falta una app?
Solo para cosas muy específicas: usar un lector de huella conectado al celular o el GPS de la ambulancia todo el tiempo en segundo plano. Si algún día hace falta, se hace una app pequeña solo para eso.
Seguridad
Entra con usuario + PIN · se bloquea sola a los 5 min · los datos guardados sin internet van cifrados · si se pierde el celular, SIVEC Admin lo desactiva con un toque.
Qué NO se hace en el celular
Consulta completa, historia clínica, recetas largas: eso va en la computadora. En el celular: ver, confirmar, firmar y registrar rápido.
