SIVEC PAP/VPH · Red Centro · Santa Cruz de la Sierra

Lista de insumos y equipos

Qué hace falta en cada lugar para usar el SIVEC PAP/VPH: el centro que toma la muestra, el laboratorio que la lee, el hospital que hace colposcopia y la gestión de la red. Incluye cómo instalar el lector de código de barras.

Precios referenciales (septiembre de 2026, mercado de Santa Cruz, en bolivianos): sirven para planificar, no para comprar. Pedir al menos tres cotizaciones antes de cualquier compra. Casi todos los centros ya tienen computadora e internet: se compra solo lo que falta.

3. Cómo instalar el lector de código de barras

No necesita programas ni drivers. El lector USB funciona como un teclado: cuando lee una etiqueta, "escribe" el código y aprieta Enter. El SIVEC ya está preparado para recibirlo.
1
Enchufar el lector en un puerto USB de la computadora. Windows lo reconoce solo en unos segundos (a veces suena un pitido).
2
Probar en el Bloc de notas: abrir el Bloc de notas y leer una etiqueta impresa por el SIVEC. Tiene que aparecer el código, por ejemplo M-26-000123, y el cursor bajar a la línea siguiente (eso es el "Enter").
3
Si el guion sale como ' o ? (M'26'000123): pasa porque el lector escribe como teclado de EE.UU. y la computadora tiene teclado latinoamericano. El SIVEC ya lo corrige solo, así que se puede usar igual. Si se quiere que salga perfecto también en otros programas: en el manual del lector, leer el código de configuración "Keyboard country: Latin American / Spanish" o "Emulate ALT + Keypad".
4
Si no baja de línea (no hace "Enter"): en el manual, leer el código "Add CR suffix" / "Enter". Casi todos lo traen activado de fábrica.
5
Code 128 activado (viene de fábrica). En lectores 2D, dejar activados también QR y DataMatrix para las etiquetas chicas de la fase 2.
6
Usarlo en el SIVEC (laboratorio): Portal → Recepción → leer el código de la hoja de remisión (se abre el lote) → leer cada lámina (queda "✓ Llegó bien") → las que no sirven se marcan con el motivo → Confirmar recepción.
Consejos: leer a 5–15 cm, con buena luz y la etiqueta sin arrugas; imprimir las etiquetas en láser; si una etiqueta no se lee, escribir el código a mano en el mismo cuadro y apretar Enter.

5. Antes de empezar en un centro nuevo (lista de control)

  • ☐ El administrador creó el establecimiento en Admin → Establecimientos (y marcó colposcopia / recibe muestras si corresponde).
  • ☐ Cada persona tiene su usuario en Admin → Usuarios (con permiso de Laboratorio o Colposcopia si corresponde).
  • ☐ La computadora quedó conectada con el código de conexión (⚙ Configuración) y cada persona entró una vez.
  • ☐ Se imprimió una hoja de etiquetas de prueba y el lector la lee (Bloc de notas).
  • ☐ Se armó un lote de prueba y el laboratorio lo recibió en su Portal.
  • ☐ Capacitación de 2 horas: registrar, armar lote, marcar resultado entregado, derivar, leer la contrarreferencia.
