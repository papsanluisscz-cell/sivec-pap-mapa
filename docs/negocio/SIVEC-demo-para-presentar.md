# SIVEC · Cómo preparar la demo para una presentación

## Una sola vez (30 minutos)
1. **Supabase → New project** llamado `SIVEC DEMO` (gratis alcanza). Anotá la contraseña de la base.
2. **SQL Editor** → pegar todo `docs/negocio/SIVEC-DEMO.sql` → **Run**. (Chrome sin traducción.)
3. **SQL Editor** → pegar todo `docs/negocio/SIVEC-DEMO-pasos-23-35.sql` → **Run** (trae también el Paso 36).
4. **Project Settings → API**: copiar la **Project URL** y la **anon public key** del proyecto DEMO.
5. En la computadora de la presentación, **crear un perfil de Chrome aparte** ("SIVEC DEMO"), para no tocar la configuración de la base real de San Luis.
6. En ese perfil, abrir el SIVEC → ⚙ **Configuración** → pegar la URL y la clave del proyecto DEMO → guardar.

## El día de la presentación
- En cualquier puerta: usuario **demo**, contraseña **demo**.
- Barra de abajo: cambiar de puerta en un clic (Admin, Red, Centro, Hospital, Laboratorio, Campaña).
- Botón **🔊 Sonidos y voz** (en la barra de la demo, o ⚙ → Sonidos → "Escuchar todos los sonidos y frases"): todos los efectos, saludos, avisos y confirmaciones, con voz femenina o masculina.
- Orden sugerido: Centro → Laboratorio → Hospital → Red → Campaña → 🔊.

## Antes de salir de casa
- Probar el volumen del proyector/parlante y la voz (Windows trae Pablo/Raúl y Helena/Sabina en español).
- Internet del celular como respaldo.
- Todo es ficticio: no abrir la base real en la presentación.
