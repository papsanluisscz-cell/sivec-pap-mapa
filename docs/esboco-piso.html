🛒 Carro de visita · lo que lleva y para qué
Cómo se usa
Un carro por piso · se carga de noche · el tablet ya abre en el piso y el orden del recorrido. En cada cama: escanear la pulsera → se abre esa paciente → preguntar, corroborar, firmar.
Por qué un carro y no el celular
Pantalla grande para que todo el equipo vea · huella para firmar · manos libres para examinar · material de curación a mano · higiene: superficie lavable y gel.
Costo aproximado
Carro metálico + tablet de 10" + lector de huella + lector de códigos + batería: equipamiento común, sin nada especial.
